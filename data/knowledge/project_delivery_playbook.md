# 范围管理

项目启动前应冻结标准交付范围。新增定制需求必须形成变更单，注明新增工时、外包成本、交付日期和合同影响。

# 工时预警

实际工时达到计划工时的 80% 且完成度不足 70% 时触发预警。高定制项目应每周复核工时偏差，避免在验收前集中暴露超支。

# 外包管理

外包只用于明确的能力或产能缺口，采购前需核对预算和毛利影响。项目经理不得将未审批外包成本延后到项目结束后补录。
